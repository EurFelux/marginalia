The Stats page has a new AI usage tab next to Reading. For the last 7 days, the last 30 days or all time, it shows how many tokens you've used, how much of the input was served from the prompt cache, and how many requests were made. A chart shows usage by day (by month for all time), split into cache reads, other input and output. Below the chart, usage is broken down by purpose (chat, summaries, reading reports, context compaction, memory consolidation, conversation naming), by model, and by book. Usage is now recorded for every AI request, including background work, and stays in the totals when you delete a conversation or regenerate a reply. Chat usage from before this update is added once from your existing conversations; usage from background work before this update and from messages already deleted can't be recovered.
