Add an AI web search tool. Toggle "web" on a message in the AI panel and the assistant can search the web (powered by Exa) for current or external information beyond the book — the search shows up as a step in the reply and sources are linked inline. Configure it under Settings → Web search by adding your Exa API key. It's off by default, the per-message toggle stays disabled until web search is configured, and backends are pluggable with automatic fallback so you can point it at another MCP search server if one runs out.
