Each AI reply now has a token usage icon next to Copy and Regenerate. Hover over it, or move keyboard focus to it, to see the model, how many steps the reply took, its input and output tokens, how much of the input was read from or written to the prompt cache, reasoning tokens, and how large the context was at the last step. Only the figures your provider reports are listed. A reply you stopped early or that failed shows the usage of the steps that finished. Replies from before this update show input and output totals only.
