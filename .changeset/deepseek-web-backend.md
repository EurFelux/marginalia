Web search can now use DeepSeek, with the API key you already set up for the built-in DeepSeek provider. The Web search page in Settings is now a list of engines: turn each one on or off and drag to set the order. The assistant tries them in that order and moves to the next one if a search fails. With DeepSeek on, the assistant can also read a full web page instead of only search snippets. Page content is marked as untrusted so instructions hidden in a page can't steer the assistant. DeepSeek search is billed per request to your DeepSeek account, so it starts off; Exa stays the default.
