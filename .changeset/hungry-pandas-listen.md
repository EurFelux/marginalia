Show what the assistant is doing while a reading report generates. The report card now displays a live timeline of each step — collecting your annotations, listing conversations, sending a helper into a long one, rereading the text — with the elapsed time, how many steps are done, and which steps were skipped. Steps that run at the same time appear side by side, and if generation fails the timeline stays put so you can see where it stopped.
