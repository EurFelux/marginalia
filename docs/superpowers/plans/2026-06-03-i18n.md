# i18n 系统 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 Marginalia 建立简体中文/英文双语 UI（含主进程错误消息）的 i18n 系统：跟随系统语言、偏好持久化、全量文案抽取、RTL-ready。

**Architecture:** 纯逻辑 + locale 资源放 `@shared/i18n`（两进程共享）；渲染层用 `react-i18next`、主进程用 vanilla `i18next` 各自薄 init；语言偏好走与 `colorMode` 同款的 `preferences` 路径；locale TS 模块由 `i18next-cli extract` 生成、类型由生成文件的 `typeof`（`as const`）推导。

**Tech Stack:** i18next 26 + react-i18next 17 + i18next-cli（dev）；Zod 4；Electron 41；Tailwind（逻辑工具类）；vitest（跑在 Electron 运行时）。

**坑（全程注意）：**

- **DOM 不在 preload 碰**：设 `<html lang/dir>` 放 renderer 入口 `src/renderer.tsx`（preload 求值时 `document.documentElement` 为 null，碰它崩整个 preload）。
- **测试 ABI**：一律 `pnpm test`（= `ELECTRON_RUN_AS_NODE=1 electron …vitest`，与 app 同 Electron ABI）。
- **prek format gate**：`git commit` 触发整仓 `format:check` + `lint:fix`；提交前先 `pnpm format`。被 hook 改动后 `git add` 再提交。
- **路径别名四处同步**：`@shared/*` 在 `tsconfig.json`、`vite.main.config.ts`、`vite.preload.config.ts`、`vite.renderer.config.ts`、`vitest.config.ts` 均有；新增 `@shared/i18n/*` 无需改别名（`@shared/*` 已覆盖子路径）。
- **类型机制说明**：locale 为 `i18next-cli` 生成的 `export default {...} as const` TS 模块 → 用 `typeof` 直接拿字面量类型做 `CustomTypeOptions`（比 `i18next types` 命令更稳，TS 模块无需再生成 d.ts）。`i18next-cli` 用于 `extract`（键同步）+ `lint`/`status`（守护），**不**用其 `types` 命令。

import { z } from "zod";

/** UI 语言（BCP 47）。源语言 zh-CN，回退 en。 */
export const uiLanguage = z.enum(["zh-CN", "en"]);
export type UILanguage = z.infer<typeof uiLanguage>;

/** 语言元数据：code + 本族名 label + 书写方向（今皆 ltr；加 RTL 语言时新增 dir:"rtl" 一条即可）。 */
export const LANGS: { code: UILanguage; label: string; dir: "ltr" | "rtl" }[] = [
  { code: "zh-CN", label: "中文", dir: "ltr" },
  { code: "en", label: "English", dir: "ltr" },
];

/** 系统 locale → 支持语言：zh* → zh-CN（只发简体），其余 → en。 */
export function matchSystemLanguage(locale: string): UILanguage {
  return locale.toLowerCase().startsWith("zh") ? "zh-CN" : "en";
}

/** 首启语言：已存偏好优先，否则按系统 locale 匹配。 */
export function resolveInitialLanguage(
  stored: UILanguage | undefined,
  systemLocale: string,
): UILanguage {
  return stored ?? matchSystemLanguage(systemLocale);
}
```

import i18next from "i18next";
import { resources } from "@shared/i18n/resources";
import type { UILanguage } from "@shared/i18n/language";

// 主进程独立的 vanilla i18next 实例（不依赖 react）。只用于本地化「自产」错误消息。
const main = i18next.createInstance();

/** 启动时按解析出的语言同步 init（幂等）。 */
export function initMainI18n(language: UILanguage): void {
  if (!main.isInitialized) {
    void main.init({
      resources,
      lng: language,
      fallbackLng: "en",
      interpolation: { escapeValue: false },
    });
  } else {
    void main.changeLanguage(language);
  }
}

/** 运行时切换主进程语言（偏好变更时调）。 */
export function setMainLanguage(language: UILanguage): void {
  void main.changeLanguage(language);
}

/** 主进程翻译函数（已由 @shared/i18n/i18next.d.ts 类型化键）。 */
export const t = main.t.bind(main);
```

`src/renderer/i18n/index.ts`：

```ts
import i18n from "i18next";
import { initReactI18next } from "react-i18next";
import { resources } from "@shared/i18n/resources";
import { LANGS, resolveInitialLanguage, type UILanguage } from "@shared/i18n/language";
import { persistPreference } from "@renderer/store/persist-preference";

/** 按语言设 <html lang/dir>（dir 取 LANGS；今皆 ltr，RTL 语言加入即自动翻转）。 */
function applyHtmlDir(code: UILanguage): void {
  const lang = LANGS.find((l) => l.code === code) ?? LANGS[0];
  document.documentElement.lang = lang.code;
  document.documentElement.dir = lang.dir;
}

const initial = resolveInitialLanguage(
  window.api.preferences.getAll().language,
  window.api.app.locale,
);

if (!i18n.isInitialized) {
  void i18n.use(initReactI18next).init({
    resources,
    lng: initial,
    fallbackLng: "en",
    interpolation: { escapeValue: false },
    react: { useSuspense: false },
  });
}
applyHtmlDir(initial);

/** 切换 UI 语言：i18next 切换 + 落盘 + 重设 dir。 */
export function changeUiLanguage(code: UILanguage): void {
  void i18n.changeLanguage(code);
  persistPreference({ key: "language", value: code });
  applyHtmlDir(code);
}

export default i18n;
```

> 确认 `persistPreference` 签名：`persistPreference({ key, value })`（见 `src/renderer/store/persist-preference.ts`，theme-store 同款调用）。`window.api.preferences.getAll().language` 类型已由 A4 注册后自动覆盖。
