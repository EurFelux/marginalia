# AI 回复默认收起过程，只显示回答 — Design

**Issue:** #128
**Date:** 2026-10-12
**Source:** 用户请求 2026-10-12（「默认折叠工具调用，只有最后一段文本常态显示」「bash 折叠是单个 tool，我们这次是 tool output 以及中间的 text 都要折叠」「汇总行减少信息量，参考 Codex 只有一个 Worked」）；实现中发现「回答之后再存记忆」的形状，用户选定「记忆类工具不切断回答」（§3.1）
**前置:** `2026-10-03-bash-block-collapse-design.md`（单个 bash 块的收起方式不变，本文在它外面再套一层）
**原型:** 应用内原型（一次性代码，未合入）比较过多种标题行，用户选定「只显示用时」的变体 A。

## 1. 背景

一轮回复里，AI 常常先说一句「我先看看目录」，再读目录、读章节、搜索、跑命令，中间还穿插几句话，最后才给出回答。现在这些内容全部按顺序铺开：每个工具占一行灰色步骤，每条 bash 是一个终端块，中间的话也照常显示。几轮工具调用下来，真正的回答被挤到很下面，而读者多数时候只关心最后的回答。

## 2. 目标与非目标

**目标**：一条 AI 回复里，回答之前的所有内容（工具调用及其结果、夹在中间的文本）收进一个折叠区，默认收起，标题行只说这一轮用了多久；回答照常显示。

**非目标**：

- 不改单个工具步骤行、单个 bash 块的样子（展开折叠区后看到的和现在一样）。
- 不记住折叠区的展开状态（重新挂载即回到收起）。
- 不加「默认展开」之类的设置项。
- 不动思考状态提示（「正在思考…」「正在准备回答…」）。
- 不给旧消息补算用时。

## 3. 设计

### 3.1 怎么切分

把消息按现有规则切成段（连续文本合并成一段，每个工具调用一段），再按工具分两类：

- **记忆类**：读、存、改、删记忆（`readMemory` / `saveMemory` / `updateMemory` / `deleteMemory`）和改人设（`updateSoul`）。
- **过程类**：其余所有工具（读书、搜索、联网、bash、技能、书库与阅读记录查询……）。

以**最后一次过程类工具调用**为界：

- 它和它之前的所有段进折叠区。
- 它之后的所有段是**常显区**，照常显示：回答文本，以及夹在其中的记忆类步骤行。
- **最后一段就是过程类工具调用**（还在调工具，或者回复中途被停止 / 出错 / 步数用尽）：常显区为空，所有段进折叠区。
- **没有过程类工具调用**（纯文本回复，或只用了记忆类工具）：没有折叠区，和现在完全一样。

折叠区放在常显区上方，保持时间顺序。

记忆类工具不切断回答，是因为 AI 常在写完回答后才存记忆，再补一句「记下了」。若按「最后一段文本」切，真正的回答会被收起，常显的只剩那句收尾。2026-10-12 统计正式库：330 条带工具调用的回复里有 51 条是这种形状，收尾前调用的全是记忆类工具。

### 3.2 收起时的标题行

折叠区收起时只剩一行：小字、灰色，行尾一个箭头 `›`，没有图标、次数或失败数。标题行有两种形态：

**进行中**：回复正在生成、且最后一个工具调用还没出结果时，标题行显示这一步本身：

```
📖 读取〈第三章〉 · 读取中…  ›
```

- 和现在的步骤行一样：工具图标、人话说明、状态，状态字闪烁。
- bash 显示为 `>_ 运行命令：<命令> · 运行中`，命令里的换行折成空格，超长省略。
- 补工具图标：bash 用终端图标（`SquareTerminal`），联网搜索用地球图标（`Globe`），记忆类用大脑图标（`Brain`），改人设用 `UserPen`。现在这些都落到兜底的扳手上。
- 记忆类工具现在显示原名（如 `saveMemory · 完成`），会出现在常显区里，补上人话说明：读取记忆、保存记忆「标题」、更新记忆「标题」、删除记忆、更新人设（标题缺失时只显示动作）。

**汇总**：其余情况（回复已结束，或工具已出结果、AI 正在想下一步）只显示这一轮的用时：

```
用时 12 秒 ›
用时 1 分 13 秒 ›
```

- 用时见 §3.3。四舍五入到秒，最少 1 秒；满一分钟拆成「N 分 N 秒」。英文 `Worked for 12s` / `Worked for 1m 13s`。
- **没有用时的时候**（回复还在生成，或者是本功能上线前的旧消息），显示「查看过程」，展开后显示「收起过程」（英文 `Show steps` / `Hide steps`）。生成结束、用时定下来后，这一行换成「用时 N 秒」。

失败的步骤不在标题行上提示，展开后各自的状态照常可见。AI 没能从失败中恢复时，回答本身会说明。

### 3.3 用时怎么记

- 用时 = 主进程开始调用模型，到这一轮结束（完成、用户停止、出错都算）的毫秒数（整数）。等待用户批准 bash 的时间也算在内，和 Codex 的「Worked for」口径一致。
- 主进程在落库这一轮回复时，把用时写进消息元数据 `metadata.durationMs`。`messages.metadata` 是 JSON 列，新增可选字段，不需要迁移。
- 计时用的时钟经 `SendDeps` 注入（同阅读报告的 `now`），测试里可控。
- 渲染层把历史消息转成界面消息时一并带上用时。一轮结束后面板本来就会从数据库重新载入最新消息（现状），所以标题行在生成结束后马上就能拿到用时，不需要额外的推送。

### 3.4 展开

点标题行切换展开 / 收起，箭头随之转向；标题行是一个按钮，可以用键盘聚焦和操作。

展开后：

- 标题行固定显示汇总形态：有用时显示「用时 N 秒」，没有显示「收起过程」。进行中的那一步已经在下面列着了，不再重复。
- 下方按原顺序列出折叠区里的所有段，左侧一道竖线把它们和回答区分开：
  - 中间文本：照常渲染 markdown，正文用灰色，表明这是过程而不是回答。
  - 工具步骤行、bash 终端块：和现在一模一样（bash 块自身仍默认收成一行，见 #126）。
- 回复还在生成时展开，新的步骤会实时出现在列表末尾；展开状态在这一轮回复结束前保持不变。

### 3.5 等待批准的 bash 不收进去

bash 命令等待批准时，用户必须看到完整命令和操作栏，所以**有挂起审批请求的 bash 块一律放在折叠区外**，紧接在折叠区下方显示（多个并行请求按原顺序排列）。用户批准或拒绝后，它回到折叠区里。

拿掉待批块后，如果折叠区里没有过程类工具调用（比如只有一句「我来导出一下」），就不出现折叠区，这些文本照常显示在待批块上方。

### 3.6 生成过程中

切分规则在生成过程中和结束后完全一样，每次渲染重新切分：

- AI 正在写的文本在常显区，照常显示（带现在的逐字淡入）；如果它写完后又调用了过程类工具，这段文本就被收进折叠区；之后只调用记忆类工具则留在常显区。
- 工具调用期间，标题行是进行中形态；工具出结果、AI 在思考或在写回答时，标题行是汇总形态（此时还没有用时，显示「查看过程」），下方照旧显示「正在准备回答…」。
- 回复结束时没有额外的收起动作，只有标题行文字换成用时。

### 3.7 复制

消息下方的复制按钮改为只复制**常显区的文本**，与常态显示的内容一致；常显区里有多段文本（中间隔着记忆类步骤行）时以空行连接。没有过程类工具调用的消息行为不变。常显区没有文本（回复以过程类工具调用结尾）时复制空串，同现在没有文本的消息。

## 4. 影响范围

主进程：

- `src/shared/types.ts`：`messageMetadataSchema` 增加可选 `durationMs`（非负整数）。

- `src/main/ai/stream-assistant.ts`：开始调用模型时记下时刻，落库时写 `metadata.durationMs`。

渲染层：

- `src/renderer/ai/process-fold.ts`（新）：纯函数——把段序列切成「折叠区 / 待批块 / 常显区」、取常显区文本、判断标题行是否为进行中形态、把用时拆成分和秒。
- `src/renderer/ai/MessageList.tsx`：`AssistantBubble` 按 §3.1 布局；新增折叠区组件；`TOOL_ICONS` 补 bash、联网搜索、记忆类、改人设；步骤行的 bash 进行中状态显示「运行中」。

## 5. 测试

- 渲染层纯函数单测：
  - 切分：纯文本 / 文本—工具—文本 / 以工具结尾 / 只有工具 / 回答—存记忆—收尾（记忆步骤留在常显区）/ 只用了记忆类工具（无折叠区）/ 记忆类在过程类之前（进折叠区）/ 待批 bash 在末尾 / 并行的两个待批 bash / 文本后紧跟待批 bash。
  - 进行中判定：生成中且末步未出结果 → 进行中；末步已出结果 → 汇总；已结束 → 汇总。
  - 用时拆分：不足 1 秒记 1 秒、四舍五入的边界（59.4 秒 / 59.5 秒）、满一分钟拆出分。
  - 常显区文本：无工具调用、单段、隔着记忆步骤的多段（空行连接）、以过程类工具结尾（空串）。
  - 历史消息转换带上 `durationMs`。
- 主进程（`send.test.ts`，注入时钟）：完成、用户停止、流级出错三种结局都写入 `durationMs`，值等于注入时钟两次读数之差。
- 在真实应用里走一遍：多步工具调用的回复（生成中与结束后，标题行从「查看过程」换成用时）、展开 / 收起、需要批准的 bash、中途停止的回复、重新打开会话后的历史消息、功能上线前的旧消息、回答之后存记忆的历史消息。
